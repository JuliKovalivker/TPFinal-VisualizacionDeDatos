## Ejecutar el proyecto

Para que el video se reproduzca correctamente, es necesario servir el proyecto desde un servidor local. Si abrís el archivo `index.html` directamente, el navegador puede bloquear la carga del video por políticas de seguridad.

1. Abrí una terminal en la carpeta del proyecto.
2. Ejecutá:

python -m http.server 8000

3. Abrí el navegador y entrá a:

http://localhost:8000/

Luego abrí `index.html` desde esa dirección.
