## Ejecutar el proyecto

> **Importante:** No abras `index.html` haciendo doble clic, ya que algunos navegadores bloquean la reproducción del video cuando el proyecto se ejecuta desde el sistema de archivos.

1. Abrí una terminal en la carpeta del proyecto.
2. Si tenés Python instalado, ejecutá:

```bash
python -m http.server 8000
```

3. Si no tenés Python, podés abrir el proyecto con **Live Server** en Visual Studio Code.
4. Entrá desde tu navegador a:

```
http://localhost:8000/
```
